## 🔥 Agni Pehchan — Thermal Anomaly Classification Platform

<a href="https://github.com/nainaaa1105/SIH_Team_AlgoRythm">
<img src="https://github-readme-stats.vercel.app/api/pin/?username=nainaaa1105&repo=SIH_Team_AlgoRythm&theme=tokyonight&hide_border=true" />
</a>

**Smart India Hackathon 2026 — NTRO Problem Statement PS162**

An end-to-end intelligence platform that processes thermal anomalies from satellite feeds and classifies events into categories such as:

`Industrial Fire` · `Gas Flare` · `Wildfire` · `Agricultural Burning` · `Mining`

### Highlights

- 🛰️ NASA FIRMS + Sentinel imagery + ESA WorldCover
- 🧩 28 engineered contextual, thermal, temporal, spatial and imagery features
- ⚡ XGBoost classification
- 🔍 SHAP-based explainability
- 📍 DBSCAN spatial clustering
- 📈 Kalman-filter escalation forecasting
- 🌫️ Atmospheric plume analysis
- 🗺️ Interactive 2D / 3D operator dashboard
- 🧪 735 automated tests across 41 test modules

🌐 **Live Platform:**  
https://sihteamalgorythm-production.up.railway.app/
